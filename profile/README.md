### What we build

- **Original games** — our own art, sound and maths, designed in-house from the first sketch.
- **Server-side outcomes** — every round is decided and recorded on the game server; the client only shows it.
- **Verified maths** — RTP and volatility checked by large simulation runs before a game ships.
- **Made for integration** — one game server and API for operators, platforms and aggregators.
